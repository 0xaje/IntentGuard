02 · The product flow

IntentGuard makes the mismatch impossible to miss.

The user defines the goal first. IntentGuard turns it into explicit limits, decodes what the wallet requests, and compares the two before value moves.
01
State intent
“Claim an airdrop. No token permissions.”
02
Decode request
Calldata or typed data becomes token, spender, amount, deadline, and chain fields.
03
Apply policy
Deterministic code returns MATCH, MISMATCH, or CANNOT VERIFY.
The engine decides. The model only explains the immutable evidence and verdict.
Confirm-first by design: no custody, no private keys, no arbitrary execution.
